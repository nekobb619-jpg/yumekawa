# pedagogy-kokugo-logic.md — 国語力の3つの論理フレームワーク

本ファイルは、福嶋式「本当の国語力」に基づく **三つの論理（因果関係・イコールの関係・対立関係）**
の教育フレームワークを、「おしえて！ラボ」のコンテンツ設計にインストールするための指針書である。
新しい国語系の問題を作成するとき、他教科の `thinking:true` 問題を設計するとき、
探偵ラボの思考力ジェネレーターを拡張するときにこのファイルを読み込むこと。

---

## 1. 中心思想：「国語力」＝「論理的思考力」

- 国語は「センス」ではなく、**筋道を立てて考え、伝える力**。
- この力は全教科の成績を底上げする（算数の文章題も、理科の実験レポートも、社会の資料読解も、
  すべて「日本語で論理的に読み・書き・考える力」が土台になる）。
- 「感情語で会話する」（ヤバい・ウケる・エモい だけで済ませる）子どもたちに、
  **言葉で正確に考え、言葉で正確に伝える** 習慣を育てることが目的。

## 2. 三つの論理（The Three Logical Relations）

すべての論理的な文章・思考は、以下の **3つの関係** に集約される。

### A. 因果関係（いんがかんけい）— Cause & Effect / Reasoning

| キーワード | 方向 | 例文 |
|---|---|---|
| **だから・そのため・したがって** | 原因→結果 | 雨がふった。**だから** かさをさした。 |
| **なぜなら・～からだ** | 結果→原因 | かさをさした。**なぜなら** 雨がふったからだ。 |

- **「なぜ？」と問い、理由を答える** 力。
- 論理の破たん（原因と結果がつながっていない推論）に気づく力。
- 【アプリでの活用】
  - ステージ `国語/論理/inga01`：因果関係トレーニング
  - 既存の `国語/言葉/setsuzoku01`（接続する言葉）は、このAの要素を含む
  - 全教科の `thinking:true` 問題で「なぜそうなるのか」を問う設計に活用
  - 探偵ラボの `genMathThinkingCondition` 等の「条件整理」問題にも因果の連鎖が含まれる

### B. イコールの関係 — Equivalence / Rephrasing / Examples

| キーワード | 方向 | 例文 |
|---|---|---|
| **つまり・すなわち・要するに** | 具体→抽象（まとめ） | りんご、みかん、バナナ。**つまり** 果物だ。 |
| **たとえば・具体的には** | 抽象→具体（例示） | 果物が好きだ。**たとえば** りんごやバナナ。 |
| **比喩（ひゆ）** | 別の似たもので表現 | 足が **棒になった**。（＝とても疲れた） |

- **抽象と具体を行き来する** 力。
- 「つまりこういうこと」とまとめる力、「たとえばこういうこと」と具体例を出す力。
- 比喩の理解（「頭が真っ白になる」「心が折れる」など、日常の慣用表現も含む）。
- 【アプリでの活用】
  - ステージ `国語/論理/equal01`：イコールの関係トレーニング
  - 既存の `国語/慣用句/kanyoku01` にも比喩・慣用表現が含まれる
  - 理科の実験結果→まとめ、社会の資料→要約 などにも応用

### C. 対立関係（たいりつかんけい）— Contrast / Opposition

| キーワード | 方向 | 例文 |
|---|---|---|
| **しかし・けれど・でも・ところが** | 予想の逆 | 練習した。**しかし** 負けた。 |
| **一方（いっぽう）・それに対して** | 並列の比較 | 犬は散歩が好き。**一方** 猫は家が好き。 |

- **反対の立場・対比的な視点** を持つ力。
- 「予想される反対意見」を自分で考える力（反論想定力）。
- 身近なもので対比する力（夏と冬、都会と田舎、犬と猫 など）。
- 【アプリでの活用】
  - ステージ `国語/論理/tairitsu01`：対立関係トレーニング
  - 既存の `国語/言葉/setsuzoku01` に逆接（しかし・けれど）の問題が含まれる
  - 探偵ラボで「◯◯な人もいれば△△な人もいる」のような多角的思考を促す

## 3. 三つの論理と既存コンテンツの対応マップ

| 既存ステージ | 対応する論理 | 備考 |
|---|---|---|
| `国語/言葉/setsuzoku01` | A + C | 「だから」（因果）・「しかし」（対立）を扱う。Bの「つまり」「たとえば」も一部あり |
| `国語/読解/kosoado01` | − | 指示語。直接の論理分類はないが、文脈把握の基礎 |
| `国語/漢字/*` | − | 語彙力は論理的思考の道具（第4章の「言葉がなければ考えられない」に対応） |
| `国語/修飾語/shushoku01` | − | 文の構造理解。主語・述語・修飾語の関係把握 |
| `探究/分岐図解/bunki01` | A | 「もし～なら」図＝条件分岐＝因果の可視化 |
| 全教科の `thinking:true` 問題 | A + B + C | 条件整理（A）・法則発見→一般化（B）・比較検討（C） |
| 探偵ラボ | A + B + C | 逆推論（A）・手がかり統合（B）・多角的推理（C） |

## 5. 問題設計ガイドライン（三つの論理を意識した問題づくり）

### 5.1 国語の問題を作るとき
- 新しい国語ステージを作るときは、**その問題がA・B・Cのどの論理を鍛えるか** を意識する。
- 1つのステージに3つの論理を混ぜても良いが、主軸となる論理を決めておくこと。
- 接続語の穴埋め問題は既に `setsuzoku01` にあるので、新しいステージでは
  **文脈の中で論理関係を見抜く力** を重視する（「この文章の中の因果関係はどれ？」など）。

### 5.2 他教科の thinking:true 問題を作るとき
- **算数**：文章題で「なぜこの式になるのか」を問う → A（因果関係）
- **理科**：実験結果を「つまりどういうことか」とまとめさせる → B（イコール）
- **社会**：「都会と田舎のちがい」「メリット・デメリット」を考えさせる → C（対立）
- **探究**：すべての論理が融合する場。特に「ねらいを見ぬこう」で3つの論理を意識化させる。

### 5.3 「問題のねらいを見ぬこう」「ニコに教えてあげよう」の設計
- 「ねらいを見ぬこう」：この問題が3つの論理のどれを鍛えているかを自覚させる。
- 「ニコに教えてあげよう」：ニコの疑問に答える形で、論理関係を自分の言葉で説明させる。
- これらのメタ認知問題は「教える＝最高の学び」の哲学（第1章）に直結する。

## 6. 漢字を「言葉」として意味中心に学ぶ（語彙力と論理力の連動）

> **漢字は「形を覚えるもの」ではなく、「言葉として使いこなす力」を育てるもの。**

### 6.1 核心思想
- 「言葉がなければ考えられない」（第4章20）：語彙が少ないと、考えの解像度が下がる。
- 漢字が **例文の中でどのような意味で、どのような使われ方をしているか** 考えながら勉強する。
- 漢字を使って **日本語について考える時間** を持つことが大事。
- 漢字の意味を考え、**語彙力** を身につけていくことが大切。
- 豊かな語彙力で、**読解力・記述力・論理力** がのびる。

### 6.2 漢字学習と三つの論理の連動

| 論理 | 漢字学習での活用 | 問題例 |
|---|---|---|
| **A. 因果関係** | 「なぜこの漢字を使うのか」を考える | 「雨が降った。**だから** 傘を出した」→「出」の意味を文脈から考える |
| **B. イコールの関係** | 同じ漢字の複数の意味、言い換え、語彙ネットワーク | 「先生」の「先」は **つまり**「先に学んでいる人」。「先」を使った言葉を集めよう |
| **C. 対立関係** | 反対語ペア、対比で意味を深める | 「上↔下」「入↔出」「大↔小」。**一方** 「大人（おとな）」の「大」は大きさだけ？ |

### 6.3 従来の形式中心 vs 新しい意味中心

```diff
- ❌ 形式中心（従来の典型問題）
-   Q: 「一年生」の「一」の読み方は？ → いち
-   Q: 「雨」の1画目はどれ？ → 横線
-   Q: 「貝」は何画？ → 7画

+ ✅ 意味中心（新しいアプローチ）
+   Q: 「水を 出す」の「出」と「家を 出る」の「出」。同じ漢字だけど、
+      意味は にているかな？ → 両方「中から外へ」の意味
+   Q: 「先生」の「先」と「先に行く」の「先」、どちらも「まえ・さき」の意味。
+      「先生」は どういう意味の 言葉かな？
+   Q: 「森」は「木」が3つ。「林」は「木」が2つ。
+      木がたくさんあるほうはどっち？ → 漢字の成り立ちから意味を発見
+   Q: 「大」の反対は？「入」の反対は？ → 対立関係で語彙を広げる
```

### 6.4 漢字コンテンツ作成時の設計指針

漢字の問題を作るとき（漢検シリーズ、国語/漢字系ステージ）は以下を守る。

1. **文脈の中で出題する**：「◯の読み方は？」ではなく「『水が流れる。』の『水』はどう読む？」
   のように、必ず例文の中で漢字に出会わせる。
2. **意味を考えさせる問題を4問以上入れる**：読み・画数だけでなく、
   「この漢字を使った言葉を見つけよう」「同じ漢字でも意味がちがうのはどれ？」を必ず含める。
3. **語彙ネットワークを意識する**：1つの漢字から広がる言葉のつながりに気づかせる
   （「水」→水曜日/水分/水田/水泳）。`job_desc` でも関連語を紹介する。
4. **反対語ペアを活用する**：対立関係（C）と連動して、反対の意味の漢字セットで語彙を倍増させる。
5. **書き順・画数は厳選する**：間違えやすいものだけに絞る（全字の書き順を問わない）。
   節約した問題枠を意味・語彙系の問題に回す。
6. **`job_desc` で語彙を広げる**：正解後の解説で、その漢字を使った他の言葉・表現を
   2〜3個紹介し、「この漢字は他にもこんな言葉で使うよ」と語彙の種をまく。

### 6.5 主語・述語の把握との関係
- 主語と述語の把握（第4章19）は、文の論理構造を見抜く基礎スキル。
  → `国語/修飾語/shushoku01` が担当（将来 `shugo_jutsugo01` で深める）。

## 8. 効率的な「暗記」の3大原則（理解・反復・イメージ）

第5章25で語られる「暗記」の真意を本アプリのコンテンツ設計・学習システムにインストールする。
丸暗記（暗記＝単なる丸覚え）は短期間で忘却するが、以下の3つのポイントを押さえた暗記は**本物の定着（思考の土台）**となる。

> **「丸暗記」ではなく、「理解し、イメージし、反復する」ことで、一生ものの知識・語彙にする。**

### 8.1 3大原則とアプリでの具体的落とし込み

| 原則 | 内容・意味 | アプリでの具体的落とし込み（設計ルール） |
|---|---|---|
| **① 理解すること**<br>(Understanding) | 理由・仕組み・背景を納得して覚える。「なぜそうなるか」が分かると記憶のフックができる。 | - `job_desc`（解説）で単なる正解発表にとどまらず「なぜそうなるのか」の理由を解説する。<br>- 「ねらいを見ぬこう」で解法の手順・ロジックを意識化させる。<br>- 漢字問題では部首の意味（「くさかんむり＝植物」など）や漢字の成り立ちを説明する。 |
| **② 反復すること**<br>(Repetition) | 1回で完璧を目指さず、時期を変えて何度も思い出す（検索練習・分散学習）。 | - ステージの `showCount` 仕組み（全14〜16問から毎回ランダム8問選出）により、同じステージでも繰り返し挑戦したくなる。<br>- 間違えた問題を自動記録する「苦手リスト（弱点克服機能）」で記憶が薄れた頃に再確認。<br>- スパイラル学習（学年をまたいだ穴うめ出題）。 |
| **③ イメージすること**<br>(Visualization) | 文字だけでなく、図・場面・エピソード・映像と結びつけて記憶を深める。 | - `branch_diagram`（分岐図解）や `canvas_code`（図形・回路等の視覚描画）の活用。<br>- ニコとの会話（`scenario`）や日常の具体的エピソード（学校・遠足・スポーツ等の場面設定）。<br>- 漢字組み立て（`kanji_build`）でパーツの形と組み合わせをビジュアル体験。 |

### 8.2 教科・問題作成時の適用ガイドライン

1. **暗記要素（漢字・語彙・公式・社会理科の知識）を出題するとき**：
   - 知識を単体で問うのではなく、**「文脈・場面（イメージ）」の中で問う**。
   - 正解後の `job_desc` で**「なぜ（理解）」を補足**する。
2. **反復を促す仕掛け**：
   - 1つの単元に複数の切り口（読み・意味・対比・図解）で同じ概念を繰り返し触れさせる。

## 9. 「感情語」依存の脱却と感情の言語化（第1章3のインストール）

第1章3「感情語で会話する子どもたち」の課題意識をアプリのコンテンツ・会話演出にインストールする。

> **「ヤバい」「ウザい」「スゴい」「最悪」一言で済ませず、自分の気持ちや状況を具体的な言葉で説明できる力を育てる。**

### 9.1 なぜ「感情語」依存が問題なのか？
- 現代の子どもたちは「ヤバい」「ウケる」「ウザい」「最悪」といった万能な感情語1つで自分の状態を表現しがちである。
- 感情語に依存すると、**「なぜそう感じたのか（因果関係）」** や **「具体的にどんな状態なのか（イコールの関係・言語化）」** を考えるステップがスキップされ、思考の解像度が下がる。
- 結果として、文章読解で「登場人物の気持ち」を正確に読み取れなくなったり、自分の意見を論理的に書けなくなったりする。

### 9.2 感情語を「思考の言葉」に変える3つの変換アプローチ

| アプローチ | 三つの論理との連動 | 具体的な変換例 |
|---|---|---|
| **① 感情語の分解・言い換え** | **B. イコールの関係**<br>（具体化・言い換え） | 「ヤバい」<br>➔ **「驚いた」「焦っている」「恐ろしい」「素晴らしい」**<br>（曖昧な感情語を、精度の高い語彙にひらく） |
| **② 感情の理由づけ** | **A. 因果関係**<br>（原因・理由） | 「むかつく！」<br>➔ **「◯◯と言われて、悔しかったからだ」**<br>（感情の裏にある原因・理由を文にする） |
| **③ 他者の感情の対比** | **C. 対立関係**<br>（対比・相手の視点） | 「自分はイライラした」<br>➔ **「自分は怒っているが、相手は悲しんでいるかもしれない」**<br>（自分と他者の感情の違いを比べる） |

### 9.3 アプリでの具体策・演出ルール

1. **相棒ニコのセリフ（モデル言語化）**:
   - ニコは子供に対して「ヤバいね！」と生返事せず、「それは**『びっくりした』**のかな？ それとも**『わくわくした』**のかな？」と具体語に言い換えて問いかける。
2. **「気持ち・感情を表す言葉」問題の強化**:
   - 国語・読解ステージで、文章中の登場人物の気持ちを「嬉しい」「悲しい」だけでなく、「心細い」「誇らしい」「申し訳ない」「もどかしい」といった豊かで精度の高い感情語から選ばせる。
3. **「伝えるノート」（記述）でのフィードバック**:
   - 単に「楽しかった」と書いた場合に、「どんな風に楽しかったかな？（例：夢中になった、胸が躍った）」と語彙を広げるナビゲーションを行う。

## 10. 「伝える力」の育成と「伝えるノート」原則（第1章2・第6章のインストール）

第1章2「伝える力のない子」、第2章9「相手がどのように感じるか」、第6章27〜29「伝えるノート」の教えをアプリの学習設計にインストールする。

> **「伝える力」とは、主観（自分だけの思い込み）を捨て、相手目線に立って「三つの論理」で言葉を組み立てる力。**

### 10.1 なぜ「伝える力」が重要なのか？
- 単に自分の気持ちを叫ぶことや、身振り手振りの「話し言葉」で済ませることは「伝えた」ことにはならない。
- 主語や理由が抜けた文（「アレがこうなったからヤバい」等）は、文脈を共有していない相手には届かない。
- 相手がどう受け取るか（客観視）を意識し、**「書き言葉」レベルの整った論理構造（主語・述語・接続語・具体例）** で構築するトレーニングが必要である。

### 10.2 「伝える力」を鍛える3つの柱

| 柱 | 内容 | アプリでの具現化 |
|---|---|---|
| **① 話し言葉 ➔ 書き言葉への昇華** | 文脈依存（その場の空気頼み）の会話から、文章単体で100%意味が伝わる「書き言葉」の構成力を育てる。 | - 「主語と述語が揃った文」「接続語でつながった文」を正解として選ばせる。<br>- 主語抜け・指示語乱用の文を正す問題を配置。 |
| **② 相手目線の客観性** | 「自分が知っているから相手も知っているはず」という主観を捨て、相手に必要な情報（理由や具体例）を添える。 | - シナリオ「問題のねらいを見ぬこう」で、「なぜ相手に理由を説明する必要があるのか」というメタ認知を育てる。 |
| **③ 「人に教える」アウトプット** | 人に教える・説明する経験が、最も深く自分の言葉を構造化（論理化）させる。 | - シナリオ**「ニコにおしえてあげよう」**問題の全ステージ展開。<br>- 子供が先生役となり、ニコの疑問に論理的に答える体験の提供。 |

### 10.3 実践「伝えるノート」コンセプト（アプリでの活用）

第6章29「伝えるノート」は、日常の出来事や学びを「三つの論理」でまとめる実践ツールである。アプリ内では以下の指針で機能・問題を構成する。

1. **三つの論理で書くテンプレ**:
   - **因果**：「◯◯だった。**なぜなら**△△だからだ。」
   - **イコール**：「◯◯が好きだ。**たとえば**△△や□□だ。」
   - **対立**：「◯◯は△△だ。**しかし**□□は〜〜だ。」
2. **AIフィードバック（評価軸）**:
   - 文章の良し悪しを感情論で評価せず、**「理由（因果）が入っているか」「具体例（イコール）があるか」「主語と述語が対応しているか」** の論理指標でフィードバックする。

## 11. 主体的探究と問題解決力（第2章5「指示待ち族」脱却のインストール）

「自分で何かを発見し、学び、吸収し、解決していく。考える力を身につけてほしい」という本プロジェクト最上位の教育目的をシステム・問題設計にインストールする。

> **正解を教え込まれる「指示待ち族」を卒業し、自ら違和感や法則を「発見」し、自力で構造化して「学び」、未知の課題を「解決」する思考力を育てる。**

### 11.1 自走する学びを育てる「主体的探究4ステップ」

```
① 発見 (Discovery) ➔ ② 仮説 (Hypothesis) ➔ ③ 構造化・吸収 (Structuring) ➔ ④ 解決・発信 (Solution & Transfer)
```

| ステップ | 子どもの体験 | アプリでの具体的な仕掛け・設計ルール |
|---|---|---|
| **① 発見 (Discovery)** | 「あれ？ 何だろう？」「なんでこうなるの？」と自発的に疑問を持つ。 | - **実験・体験ラボ (`lab/*.html`)**: 空気てっぽう、電気回路、角度レーダー、プログラミング等のインタラクティブ体験。<br>- **探偵ラボ**: 手がかりから不思議・矛盾を自分で見つける。 |
| **② 仮説 (Hypothesis)** | 「もし〜なら、こうなるのでは？」と筋道を立てて予測する。 | - **`branch_diagram`（分岐図解）**: 「もし◯◯なら➔どうなる？」の条件分岐を図で視覚化。<br>- 選択肢で「自分の予測」を選ばせる。 |
| **③ 構造化・吸収 (Structuring)** | 「なるほど！ つまりこういう法則か！」と納得して自分の血肉にする。 | - **「三つの論理」**: 因果・イコール・対立を使って頭の中を整理。<br>- **`job_desc`**: 単なる丸暗記ではなく仕組み・背景の理由を解説。 |
| **④ 解決・発信 (Solution)** | 獲得した思考力で未知の問題を解き、人に教える。 | - **`thinking: true`（思考力・推論問題）**: 複数条件を組み合わせて自力で唯一解を導く。<br>- **「ニコにおしえてあげよう」**: 自分の言葉でニコに解説し、学びを完結させる。 |

### 11.2 問題作成者への要求ルール（指示待ちを作らない問問）

1. **答えを先に与えない**: 「◯◯は△△です。では〜〜」と知識を注入する問い方を避け、「なぜこうなったと思う？」「この共通点は何だろう？」と子どもに発見させる問いかけにする。
2. **「ねらいを見ぬこう」で目的を自覚させる**: 「自分が今何のためにこの問題を解いているのか」を自分で見抜くメタ認知を全ステージに組み込む。
3. **間違えた時が最大の発見のチャンス**: 不正解時も単に「バツ」とするのではなく、「おしい！ ◯◯の条件をもう一回見てみよう」と自己解決へのヒント（`hint` / `rescue_hint`）を提示する。
