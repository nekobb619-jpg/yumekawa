# お宝図鑑（コレクション）— レア度・拡張方針

対象コード：`index.html` 内 `window.TREASURE_LIST` / `window.rollTreasureDrop` /
`window.showTreasureReveal` / `window.openTreasureBookModal`（実装の全体像は
`architecture-content.js.md` の「8. お宝図鑑」を参照。ここではデータ設計・
今後の拡張ルールだけをまとめる）。

## 1. レア度階層（2026-07-24 改定）

| レア度 | 呼び方       | 現在の種類数 | 排出重み | テーマカラー |
|--------|--------------|--------------|----------|--------------|
| ★1     | ふつう       | 13種         | 65%      | グレー（無地）|
| ★2     | レア         | 9種          | 25%      | 青系 `#60a5fa` |
| ★3     | 超レア       | 4種          | 8%       | アンバー系 `#f59e0b` |
| ★4     | 伝説級       | 2種          | 2%       | 紫系 `#a855f7`（r3より強い発光アニメーション）|

- 全体のドロップ率は変更なし：ステージクリアごとに **15%** の確率で1個抽選
  （`Math.random() >= 0.15 return null` の外枠は据え置き）。
- レア度の重みは `window.rollTreasureDrop()` 内の
  `r < 0.65 ? 1 : (r < 0.90 ? 2 : (r < 0.98 ? 3 : 4))` で決定。
- ★4は「存在するだけで特別」なレベルを想定（現状2種のみ、複数持っていても
  automatically コンプ扱いにはしない＝図鑑コンプ演出は将来の拡張候補）。

## 3. テーマ・命名の一貫性ルール（今後アイテムを足すときも踏襲する）

- 世界観のキャラクター（ニコ＝ユニコーン的マスコット、クロぽん）や
  「意図を見ぬく力」（このアプリのaim-recognition問題形式）、宝島クラフト、
  漢検10級のテーマから外れないこと。
- 見た目・意味ともに小学校低学年〜中学年の子どもにポジティブで安心できる
  ものにする（怖い・生々しい表現は禁止。persona-yumekawa.mdの表現ルールに準拠）。
- `desc`は1〜2文、子どもが読める語彙で。絵文字iconは他アイテムと視覚的に
  被らないものを選ぶ（今回`t27`の💎は既存アイテムと非重複を確認ずみ）。
- idは`t` + 連番（歯抜けなし）。既存の番号は変更しない（セーブデータの
  `treasureBook`キーとして永続化されるため、idのリネームは既存プレイヤーの
  コレクションを破壊する＝**絶対に既存idをリネーム/再利用しない**）。

## 4. 今後の拡張チェックリスト

新しいお宝バッチを追加するときは、以下を順番に実施する：

1. `window.TREASURE_LIST`に新規オブジェクトを追記（既存idの直後、レア度ごとに
   まとまりを保つ）。
2. 排出重みを変える場合のみ`rollTreasureDrop()`の閾値式を更新
   （個数が増えるだけなら閾値は変更不要。同一レア度内の抽選は
   `pool[Math.floor(Math.random() * pool.length)]`で均等ランダムなので、
   種類が増えるほど1種あたりの体感排出率は下がる想定でOK）。
3. 新レア度階層を新設する場合のみ`showTreasureReveal()`と
   `openTreasureBookModal()`のクラス分岐・CSSを追加（★5を作る場合は
   `.treasure-reveal-box.r5`等のパターンを踏襲）。
4. Node での構造検証（id重複なし・レア度カウント）＋ 統計シミュレーション
   （数百万回試行で実測排出率が設計値に近いか）＋ Playwrightでの描画確認
   （新レア度の演出モーダル・図鑑グリッド）を必ず実施してから納品する。
5. このファイルの表・リストと、`architecture-content.js.md`の「8. お宝図鑑」
   セクションの種類数を両方更新する。

## 5. 既知の設計判断メモ

- ダブり（重複）は「はずれ無し」設計として欠片+2に還元する。★4のダブりも
  同様の扱い（特別な救済処置は現状なし。将来的に「★4ダブり時は+多めの欠片」
  等の差別化を検討してもよい）。
- 図鑑コンプ報酬（全28種達成時の特別演出やごほうび）は現状未実装。
  ユーザーから要望があれば次の拡張候補とする。
