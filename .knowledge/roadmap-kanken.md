## ★ 核心思想：漢字を「言葉」として意味中心に学ぶ（2026-08-12 追加）

> **漢字は「形を覚えるもの」ではなく、「言葉として使いこなす力」を育てるもの。**

### なぜ意味中心が大事か
- 漢字を使って **日本語について考える時間** を持つことが大事。
- 漢字が **例文の中でどのような意味で、どのような使われ方をしているか** を考えながら勉強する。
- 漢字の意味を考え、**語彙力** を身につけていくことが大切。
- 豊かな語彙力で、**読解力・記述力・論理力** がのびる。
  （→ `.knowledge/pedagogy-kokugo-logic.md` の三つの論理フレームワークと連動）

### だい1回〜だい4回の反省（形式中心だった）
既存のだい1回〜だい4回は「読み → 書き順 → 画数 → 書取」の **形式中心** で構成した。
これは漢検の出題形式に対応しており、試験対策としては有効だが、
**漢字を言葉として使いこなす力** は十分に育てられていなかった。

例（だい1回の典型的な問題）：
```
❌ 形式中心の問い方（従来）
Q: 「一年生」の「一」の 読み方は？ → いち/に/さん/し
Q: 「雨」の 1画目は どれ？ → 横線/たて線/てん/コの形
```

### だい5回以降の新アプローチ（意味・語彙中心）

だい5回以降は、従来の形式問題を **減らし**、以下の「意味・語彙」系問題を **大幅に増やす**。

#### ① 文脈の中で意味を考える問題
同じ漢字でも、使われる場面で意味がちがうことに気づかせる。
```
✅ 意味中心の問い方（新）
Q: 「水を 出す」の「出」と「出口」の「出」、意味が にているのは どっち？
   A:「外に いく」ということ  B:「中に はいる」ということ
Q: 「先に 行く」の「先」と「先生」の「先」。「先生」は どういう意味の 言葉かな？
   A: まえを あるく人  B: まなびの みちを さきに すすんでいる人
```

#### ② 同じ漢字を使った言葉をあつめる問題（語彙ネットワーク）
1つの漢字から広がる言葉のつながりに気づかせる。
```
Q: 「水」を 使った 言葉は どれ？ ぜんぶ えらんでみよう！
   水曜日 / 水分 / 水田 / 水泳 → ぜんぶ「水」が つく言葉だ！
Q: 「生」を 使った 言葉を 見つけよう。次のうち「生」が 入る言葉は？
   A: 生まれる  B: 先生  C: 生きる  D: ぜんぶ
```

#### ③ 漢字の意味から考える問題
漢字の成り立ちや意味を手がかりに、日本語の仕組みを発見させる。
```
Q: 「森」は「木」が 3つ。「林」は「木」が 2つ。
   木が たくさんある ほうは どっち？ → 森と林のちがいに気づく
Q: 「赤ちゃん」「青空」「青虫」。色の漢字が入っているけど、
   「青虫」は ほんとうに 青い色？ → 言葉の意味と実際のちがいを考える
```

#### ④ 言い換え・説明する問題（論理 B「イコールの関係」と連動）
漢字の意味を自分の言葉で説明する力を育てる。
```
Q: 「千円」の「千」は どういう意味？
   A: 100が 10こ あつまった 数  B: 10が 10こ あつまった 数
Q: 「川」と「水」、どちらも「みず」に 関係あるけど、ちがいは なに？
   → 川は水が流れる「場所」、水は「もの」そのもの
```

#### ⑤ 反対の意味の漢字を考える問題（論理 C「対立関係」と連動）
```
Q: 「大」の 反対の 漢字は？ → 小
Q: 「入る」の 反対の 意味の 漢字は？ → 出
Q: 「上」「下」のように、反対の 意味の ペアを 見つけよう：「男」の 反対は？ → 女
```

## 漢検コンテンツ特有の注意点（絶対）
- **問題文（`q`）にふりがな（読みがな）を書かない。** 読み方そのものを問う問題なので、
  ふりがなを書くと答えが漏れてしまう（例：「雨（あめ）が ふる」の「雨」の読み方は？→アウト）。
  `job_desc` や `hint`（正解後や間違えた後に見せる解説）にはふりがなを使ってよい。
- **画数・書き順は、出題前に必ずWeb検索でファクトチェックする。** 複数の専門サイト
  （kakijun.jp、kanji.jitenon.jp など）を見て、内容が一致した確実なものだけ出題する。
  サイトによって説明が食いちがう場合（例：「王」の1画目は縦が先か横が先か情報源で割れていた）は、
  無理に出題せず見送ること。誤った書き順を教えてしまうリスクの方が、問題数が1つ減るリスクより大きい。
- **語彙・意味の問題を作るときも、実際の小学1年生の語彙レベルを超えないよう注意する。**
  「先生」「水田」など教科書に出る語は使ってよいが、日常的でない熟語は避ける。
